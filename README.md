# Mintlify Clone

A static website clone of the Mintlify landing page, built using HTML5 and CSS3.

## Description

This project is a faithful recreation of the Mintlify documentation platform's homepage. It features a modern, responsive design with sections for hero content, features, trusted companies, and more.

## Tech Stack

- **HTML5**: For the structure and content of the webpage
- **CSS3**: For styling, including modern features like backdrop-filter for glass effects
- **Google Fonts**: Inter, Open Sans, Roboto, and Sora fonts for typography

## Features

- Responsive header with navigation and call-to-action buttons
- Hero section with background image and email signup
- Documentation preview section
- Trusted by section with company logos
- Features section highlighting AI integration capabilities
- Modern glassmorphism design effects

## How to Run

1. Clone the repository
2. Open `index.html` in your web browser

No build process or dependencies required - it's a pure static website.

## Assets

All images and icons are stored in the `assets/` folder. These include:
- Company logos (SVG format)
- Feature images (PNG format)
- Background images
- Icons and emblems
